====================================================================
SAP Smart Form ZTEST_SF - Manual Creation Guide (10 minutes)
Equivalent of Adobe Form ZTEST_SFP
====================================================================

Step-by-step creation in transaction SMARTFORMS.
Skip the XML upload approach - create the form by hand in the GUI.

--------------------------------------------------------------------
STEP 0  Delete any leftover form
--------------------------------------------------------------------
1. SE38 -> ZTEST_SF_UPLOAD (if you used it before, just to clean tables)
   - The new version of this program also wipes STXFADM/STXFOBJ rows.
2. Or in SMARTFORMS: enter ZTEST_SF, menu Form -> Delete (confirm).
3. Verify: SMARTFORMS -> ZTEST_SF -> Display -> message
   "Smart form ZTEST_SF does not exist".

--------------------------------------------------------------------
STEP 1  Create the form
--------------------------------------------------------------------
1. Transaction SMARTFORMS.
2. Form name: ZTEST_SF.
3. Click "Create".
4. Description: "Sales Order Items - Smart Form".
5. Save (Ctrl+S). Package: $TMP (or your dev package).

--------------------------------------------------------------------
STEP 2  Form Interface (left tree -> Global Settings -> Form Interface)
--------------------------------------------------------------------
Tab: Import
   Add row:
      Parameter Name : VBELN
      Type assignment: TYPE
      Reference type : VBELN
      Optional       : (unchecked)
      Pass Value     : (unchecked)
Tab: Tables, Exceptions - leave default.

--------------------------------------------------------------------
STEP 3  Global Definitions (left tree -> Global Settings -> Global Definitions)
--------------------------------------------------------------------
Tab: Global Data
   Add rows:
      Variable Name | Type Assignment | Reference Type
      ------------- | --------------- | --------------
      LV_VBELN      | TYPE            | VBELN
      IT_VBAP       | TYPE            | TY_VBAP1
      WA_VBAP       | TYPE            | TY_VBAP

Tab: Types
   Paste this code:

      TYPES: BEGIN OF ty_vbap,
               vbeln TYPE vbeln_va,
               posnr TYPE posnr_va,
               matnr TYPE matnr,
               matwa TYPE matwa,
             END OF ty_vbap.
      TYPES: ty_vbap1 TYPE STANDARD TABLE OF ty_vbap.

Tab: Initialization
   Output Parameters: add IT_VBAP
   Code:

      lv_vbeln = vbeln.
      SELECT vbeln posnr matnr matwa FROM vbap
        INTO TABLE it_vbap
        WHERE vbeln = lv_vbeln.

Save.

--------------------------------------------------------------------
STEP 4  Pages and Windows
--------------------------------------------------------------------
The form already has %PAGE1 and a MAIN window by default.
No changes needed at this level.

--------------------------------------------------------------------
STEP 5  Add a Loop node inside MAIN window
--------------------------------------------------------------------
1. Right-click MAIN -> Create -> Flow Logic -> Loop.
2. Name : %LOOP1
   Description: Items Loop
3. Tab: Data
      Internal Table: IT_VBAP  INTO  WA_VBAP
4. Save.

--------------------------------------------------------------------
STEP 6  Add a Text node inside the Loop
--------------------------------------------------------------------
1. Right-click %LOOP1 -> Create -> Text.
2. Name : %TEXT1
   Description: Line
3. Text type: Text element (default).
4. Click in the editor area on the right side, type:

      Sales Doc &VBELN& | Item &WA_VBAP-POSNR& - Material
      &WA_VBAP-MATNR& (Customer Mat: &WA_VBAP-MATWA&)

   Notes: variable names are wrapped in & on both sides.
   Use the "Insert Field" button (toolbar) to insert &VBELN&, etc.,
   so the format is preserved correctly.
5. Save.

--------------------------------------------------------------------
STEP 7  Activate
--------------------------------------------------------------------
1. Press Ctrl+F3 (Activate) or click the green check icon.
2. Status bar: "Smart form ZTEST_SF activated".
   If errors appear, double-click the error to jump to the offending
   node, fix, save, and re-activate.

--------------------------------------------------------------------
STEP 8  Test via the driver
--------------------------------------------------------------------
1. SE38 -> ZTEST_SF_DRIVER -> F8.
2. Enter a valid sales order number (e.g. one from VA03).
3. Print preview should show one line per VBAP item.

--------------------------------------------------------------------
DONE
--------------------------------------------------------------------
This manual approach bypasses all XML upload complexity and is the
SAP-recommended way to create Smart Forms. Once activated, the
generated function module /1BCDWB/SF<nnn> can be called from the
driver program (already configured in ZTEST_SF_DRIVER.abap).
